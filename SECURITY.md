# güvenlik

bu sistem bir kapıyı açıp kapatıyor, o yüzden açıklar önemli.
bir açık bulduysan issue açma. github'ın özel bildirim yolunu kullan:
**security → report a vulnerability**.

ne bulduğunu, nasıl tekrar edildiğini ve neyi etkilediğini kısaca yaz.
düzeltme çıkmadan ayrıntı paylaşılmaz.

desteklenen sürüm: yalnızca `main` dalı.

---

**in short (english).** this system drives a door lock, so security reports matter.
please don't open a public issue; use github's private reporting
(security → report a vulnerability). only the `main` branch is supported.
