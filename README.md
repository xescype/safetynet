# SafetyNet (IUDS)

Intruder-Unaware Defence Systems — ev güvenlik sistemi projesi. Kod adı eski: SafetyNet.

## İçerik

- `docs/` — proje dokümantasyonu (fikir, güvenlik, mimari, donanım, kameralar, kayıt şeması, ağ izolasyonu, mobil app vb.) — bkz. `SAFETYNET.md` için indeks
- `SAFETYNET.md` / `SAFETYNET-FULL.md` — proje özeti
- `iuds-core/` — Rust çekirdek
- `iuds-panel/` — web paneli (Vite)
- `iuds-vision/` — görüntü işleme (Python)
- `RuView-main/`, `VoiceStudio-main/` — yardımcı adapter projeleri (MQTT presence, ses ara katmanı)
- `tools/` — yardımcı scriptler
- `safetynet notes/` — çalışma notları
- `buggedchatslog/` — hata ayıklama sohbet kayıtları

## Durum

Fikir aşaması, kurulum memleket dönüşü bekliyor.
